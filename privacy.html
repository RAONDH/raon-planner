라온 플래너 개인정보처리방침

시행일: 2026년 11월 15일

1. 이 앱이 접근하는 구글 정보

사용자가 직접 구글 계정으로 로그인하고 허락한 경우에만 아래 정보에 접근합니다.

  • 구글 계정 이메일 주소 — 연결된 계정을 구별하기 위해
  • 구글 캘린더 — 캘린더 목록과 일정을 보여 주고, 사용자가 앱에서 만든 일정을 등록·수정·삭제하기 위해
  • 지메일 (읽기 전용) — 안 읽은 메일 수와 중요 메일의 보낸 사람·제목·첫 줄을 보여 주기 위해. 메일을 보내거나 지우거나 바꾸지 않습니다.
  • 구글 Tasks — 앱의 할 일 목록과 구글 Tasks를 동기화하기 위해

2. 정보의 저장 위치

가져온 정보는 사용자의 맥 안에만 저장됩니다. 로그인 정보(토큰)는 맥의 키체인에 보관합니다. 앱 개발자나 다른 서버로 정보를 보내지 않습니다. 구글 API와의 통신은 사용자의 맥과 구글 사이에서만 이루어집니다.

3. 제3자 제공

사용자의 구글 정보를 판매하거나, 광고에 사용하거나, 제3자에게 제공하지 않습니다.

단, 사용자가 설정에서 'AI 아침 요약' 기능을 직접 켠 경우에 한해, 일정 제목·시각과 중요 메일의 보낸 사람·제목이 요약을 위해 Anthropic(Claude API)으로 전송됩니다. 메일 본문은 전송하지 않습니다. 이 기능은 기본적으로 꺼져 있습니다.

4. 구글 API 서비스 사용자 데이터 정책 준수

라온 플래너가 구글 API로 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용(Limited Use) 요구 사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

5. 정보 삭제

앱 설정에서 계정 연결을 해제하면 해당 계정의 저장된 정보와 로그인 정보가 맥에서 삭제됩니다. 구글 계정의 보안 → 타사 앱 액세스에서도 언제든지 권한을 취소할 수 있습니다.
